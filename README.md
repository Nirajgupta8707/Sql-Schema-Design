# 🗄️ SQL Schema Design Project

## 📌 About

This project focuses on designing a **relational database schema** for a real-world application. The project demonstrates database design, relationships between entities, and structured data organization.

## 🛠️ Technologies

* SQL
* MySQL
* Relational Database Design

## 📚 Concepts Covered

* Database Schema Design
* Tables & Relationships
* Primary Keys & Foreign Keys
* ER Diagram
* Normalization
* Constraints
* One-to-One & One-to-Many Relationships
* SQL Queries
